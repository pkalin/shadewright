# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be respectful and constructive in issues, pull requests, reviews and every other project space;
harassment, personal attacks, discriminatory remarks and publishing other people's private information are not
tolerated.

## Reporting

The maintainer is [pkalin](https://github.com/pkalin). Report a concern privately through GitHub's
[security advisory form](https://github.com/pkalin/shadewright/security/advisories/new) of this repository,
which only the maintainer can read; mark it as a conduct report in the title. It is the private channel the
project has, and it works for this too. Reports are read within 7 days and handled as the Covenant's
enforcement guidelines describe, from a private warning to a permanent ban, in proportion to the behaviour.

The maintainer's own conduct can be reported the same way; when the project has more than one maintainer, a
report about one of them goes to the others.
