Invariant 4. Look for an input that makes this change release text that the code before it hides: a key
written another way, a value split over two fields or lines, an encoding the rule does not decode, a
duplicate or case-variant JSON key, a caller that drops the "withheld" flag. An entry over its work budget
is withheld whole, never cut. A change to a parser, matcher or rule comes with generated corpus tests
whose answers are known by construction; say so when it does not.
